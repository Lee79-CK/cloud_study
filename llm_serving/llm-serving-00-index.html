LLM 서빙 플랫폼
설계·구축·운영 26편

GPU 한 장 위에 vLLM 엔진 하나를 띄우는 것에서 시작해, 쿠버네티스 GPU 플랫폼·추론 라우팅·AI 게이트웨이·튜닝·자동 확장·관측·보안·안전한 변경을 거쳐, 고객에게 파는 MSP 서비스 설계까지 이어지는 강의 시리즈입니다. 모든 편은 개념 설명, 직접 조작해 보는 계산기·시뮬레이터, RKE2 랩에서 따라 하는 실습, 오해 정리, 용어 사전, 확인 퀴즈로 구성되어 있습니다.

대상 신입~중급 클라우드·AI 엔지니어 구성 26편 · 6레벨 기준 2026년 10월
어디서 시작할까?

01시리즈 소개

“모델을 띄우는 법”이 아니라 “여러 고객에게 안정적으로 서빙하는 플랫폼을 만들고 운영하는 법”을 다룹니다.

  • 측정하고 결정한다: 모든 설정·용량·확장·변경을 계산과 실측으로 정합니다. 각 편의 계산기는 원리를, 실습은 실제 숫자를 줍니다.
  • 한 번에 하나씩, 기록하며: 7편에서 만든 kustomize 랩 위에 오버레이를 쌓아 가며, 바꾼 것과 결과를 남깁니다.
  • 정책은 한 곳에, 증거는 남게: 게이트웨이·기록 규칙·GitOps로 정책과 근거를 한 곳에 모읍니다.
  • 사용자가 겪는 것으로 판단한다: SLO·오류 예산·품질 SLI로 운영하고, 경보는 증상으로 호출합니다.
  • MSP 관점: 모든 편에 고객별 격리·과금·보고·계약 관점의 절이 있습니다.

각 편의 구성

시작하기 전에(학습 목표·비유) → 개념 장들 → 인터랙티브 계산기·시뮬레이터 → MSP 관점 → 흔한 오해 → 실습 → 용어 사전 → 확인 퀴즈 → 정리와 체크리스트 → 다음 편 예고.

갱신 사항 (뒤 편에서 바뀐 내용)
  • 10편 WVA → 18편: llm-d의 워크로드 변형 오토스케일러(WVA)는 사용 중단되었습니다(v0.9.0이 마지막). 자동 확장은 18편의 KEDA + EPP 지표 경로를 따르세요.
  • 11편 → 12편: Envoy AI Gateway는 2026년 9월 Agent Router로 이름이 바뀌었습니다. CRD·API 그룹·Helm 차트 이름은 그대로입니다.
  • 10·11편 → 18편: llm-d 0.10이 나왔습니다. 10·11편의 v0.9 기준 설명은 유효하지만 설치 시 최신 릴리스 노트를 확인하세요.
  • 14편 tune.sh: 도착률 목록을 ""로 주면 기동만 하도록 고친 수정본이 있습니다(15편 실습에서 사용). 14편 파일을 15편 작성 시점의 것으로 받으세요.
  • 18편 → 20편: 18편의 랩용 Prometheus는 20편에서 kube-prometheus-stack으로 대체하고, KEDA 주소·쿼리를 기록 규칙으로 바꿉니다.

08이용 안내

파일을 내려받아 오프라인으로 볼 수 있습니다.

  • 파일 배치: 이 목차(llm-serving-00-index.html)와 26개 편 파일을 같은 폴더에 두면 카드의 링크가 바로 열립니다.
  • 테마: 각 페이지 오른쪽 위 버튼으로 다크·라이트 테마를 바꿉니다. 인쇄하거나 PDF로 저장할 때는 라이트 테마를 권장합니다.
  • 코드 복사: 코드 블록의 “복사” 버튼을 쓰세요. 실습 명령의 <…>는 환경에 맞는 값으로 바꿔야 하는 자리입니다.
  • 숫자: 계산기·시뮬레이터의 값은 원리 설명용 단순 모델이고, 단가는 예시입니다. 결정에는 실습의 측정값을 쓰세요.
  • 외부 사이트: 일부 실습은 Hugging Face·GitHub·컨테이너 레지스트리 접근이 필요합니다. 버전은 각 프로젝트 릴리스 페이지에서 확인해 고정하세요.
