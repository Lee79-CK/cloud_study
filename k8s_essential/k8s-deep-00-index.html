실습 환경

3편에서 만든 실습 랩을 시리즈 전체에서 씁니다. 컨텍스트 이름은 모든 실습 명령에서 같습니다.

컨텍스트구성주로 쓰는 편비용·주의
lab-nativekubeadm, multipass VM(cp1·w1·w2), 스냅샷 3개4~6, 9~11, 14, 17~18, 21~22, 24~25로컬 자원. 기능 게이트·API 서버 플래그 실험은 여기서만
lab-rke2RKE2 서버 + 에이전트(14편에서 확장)5, 7, 14, 17, 19로컬 자원. Longhorn·Rook 실습은 디스크 여유 필요
lab-ocpOpenShift Local(CRC) 단일 노드5, 8, 9, 17, 19, 21, 24~25메모리 많이 필요. 단일 노드라 EgressIP·RWX 등 일부 제한
lab-eksEKS + 관리형 노드 그룹5, 7, 12~13, 15~16, 19~20, 23~25과금. LB·NAT·EBS 정리 필수
lab-aksAKS(Entra ID 통합)5, 7, 13, 19, 20, 23과금. Entra 그룹 생성 권한 필요
lab-gkeGKE Standard(존 클러스터)5, 8, 13, 16, 19, 23과금. 실습 후 노드 풀 축소
함정: 클라우드 실습 뒤 정리 대부분의 비용은 실습이 끝난 뒤 남은 LoadBalancer, NAT 게이트웨이, 디스크·스냅샷에서 나옵니다. 각 편 실습 마지막의 정리 명령을 꼭 실행하고, 16편의 비용 점검 스크립트로 남은 리소스를 확인하세요.
5

읽는 법

모든 편은 같은 구조입니다: 맨 위 인터랙티브 도구 → 0장(읽는 법·목표) → 본문 → 실습 → 현장 사례 → 점검 퀴즈 → 용어·약어 사전 → 다음 편. 본문에는 네 종류의 상자가 있습니다.

쉬운 말로어려운 개념을 일상 비유로 먼저 설명합니다. 처음 보는 주제라면 여기부터.
시니어 포인트문서에 잘 안 나오는 설계 판단, 운영 경험에서 나온 관점.
함정자주 빠지는 실수와 그 결과. 고객 환경 점검표로 바로 쓸 수 있습니다.
현장 메모MSP 업무에서 고객과 일할 때의 실무 팁.
  • 점선 밑줄 용어는 마우스를 올리거나 누르면 정식 명칭과 쉬운 설명이 나옵니다(5편부터). 같은 설명이 각 편 끝 용어 사전에도 있습니다.
  • 테마는 오른쪽 위 버튼으로 바꾸며, 모든 편이 같은 설정을 공유합니다.
  • 코드 블록의 “복사” 버튼으로 실습 명령을 그대로 복사할 수 있습니다. 회색 주석은 설명이며 함께 복사됩니다.
  • 버전 정보는 2026-10 기준입니다. 각 편 마지막의 “확인이 필요한 부분”은 분기마다 다시 점검하세요.
