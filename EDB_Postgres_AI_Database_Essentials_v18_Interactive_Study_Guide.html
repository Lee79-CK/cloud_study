추천 학습 순서

  1. 아키텍처·설치 → 설정·접속
  2. SQL·트랜잭션 → 운영·VACUUM
  3. 백업·PITR → 보안
  4. 성능 → 복제·HA
  5. EPAS 전용/Oracle 호환 도구 암기

키보드: 1~4 선택 · N 다음 미풀이 · R 랜덤

① 설정 파일 3종

postgresql.conf = 서버 동작

pg_hba.conf = 누가/어디서/어떻게 인증

postgresql.auto.conf = ALTER SYSTEM 기록

② 유지보수

VACUUM = dead tuple 재사용 + XID 관리

ANALYZE = Planner 통계

VACUUM FULL = rewrite + 강한 잠금

③ 관측 뷰

pg_stat_activity = 세션/쿼리/대기

pg_locks = Lock

pg_stat_user_tables = table activity/vacuum

④ 백업

pg_dump = 논리 DB

pg_dumpall = 전체 DB + global objects

pg_basebackup = 물리 base backup

PITR = Base + 연속 WAL

⑤ 메모리

shared_buffers = 공유 데이터 페이지 cache

work_mem = sort/hash 작업별 사용 가능

work_mem은 동시성 × 연산 수를 반드시 고려

⑥ 인덱스

B-tree = equality/range/order

GIN = JSONB/array/full-text

BRIN = huge + physically correlated

⑦ 복제

Streaming replication = WAL 전송/재생

Replication slot = 필요한 WAL 보존

Promotion = standby → primary

Replication만으로 HA가 완성되는 것은 아님

⑧ EPAS Security

TDE = at rest

SQL/Protect = SQL injection 방어

EDB*Wrap = 소스 난독화

Redaction = 표시 데이터 마스킹

VPD = fine-grained/row access

⑨ EPAS Performance

Query Advisor = 인덱스 후보

Dynatune = dynamic resource tuning

Wait States = 대기 진단

SQL Profiler = 비효율 SQL 탐색

⑩ Oracle 호환 도구

dblink_ora = 원격 Oracle 조회

OCL = OCI 호환 연결

ECPGPlus = C embedded SQL

EDB*Loader = bulk load
