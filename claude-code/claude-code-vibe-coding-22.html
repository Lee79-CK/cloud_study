요구사항 인터뷰

4편의 “인터뷰 받기”를 씁니다. 큰 기능일수록 Claude가 먼저 묻게 하면, 여러분이 생각지 못한 결정(누가 보나, 무엇을 하지 않나)이 드러납니다. 결과는 SPEC.md로 남기고, 이후 모든 세션이 이 파일을 기준으로 합니다.

MSP 당번용 운영 콘솔을 만들려고 해. 바로 만들지 말고 먼저 나를 인터뷰해줘. - 한 번에 질문 하나씩, 10개 이내 - 누가 언제 보나, 무엇을 보여 주나, 무엇을 하지 않나(비목표), 보안, 완료 조건을 꼭 물어봐 - 끝나면 SPEC.md 초안을 써줘. 비목표 절을 반드시 넣어
📄 SPEC.md (인터뷰 정리본)
# ACME 운영 콘솔 — 요구사항 (인터뷰 정리본) ## 목적 MSP 당번이 아침과 장애 때 한 화면에서 ACME 상태를 보고, 맞는 런북으로 바로 간다. ## 보여 줄 것 1. 서버 연결: servers.txt 의 호스트·포트에 TCP 연결 (1.5초 제한) 2. 쿠버네티스 문제 파드: k8s-ro MCP(12편)의 get_pods, Running/Completed 가 아니거나 재시작 5회 이상 3. 오늘의 점검 보고서: reports/ 의 가장 최근 json (19편) 4. 자동화 비용: 합계·중앙값·이상치 (20편) 5. 문제마다 해당 런북 링크 (10편 docs/runbooks) ## 하지 않을 것 (비목표) - 어떤 것도 바꾸지 않는다: 재시작·삭제·배포 버튼 없음. 읽기 전용 GET 만. - 로그인 기능을 만들지 않는다. 대신 127.0.0.1 에만 묶고, 원격에서는 SSH 터널로 본다. - 외부 패키지를 쓰지 않는다 (Python 표준 라이브러리). ## 보안 요구사항 (5편 8장 점검표) - 127.0.0.1 바인딩, GET 외 메서드 거부 - 셸 실행 없음 (subprocess 리스트 인자, MCP 는 stdio) - 런북 이름은 ^[a-z0-9-]+$ 이고 런북 폴더 안 실제 파일만 (경로 탐색·심볼릭 링크 탈출 방지) - 화면은 textContent 로만, CSP default-src 'self' - 모든 외부 호출에 시간 제한, 한 수집기가 실패해도 화면 전체는 뜬다 ## 완료 조건 - python3 -m unittest discover -s tests -t . 전부 통과 - /code-review 에서 높음 이상 지적 0 - 비운영 환경에서 10분 이상 띄워 두고 30초 자동 갱신 확인
비목표가 가장 중요한 줄입니다 “재시작 버튼 없음”, “로그인 없음 대신 127.0.0.1”, “외부 패키지 없음”. 이 세 줄이 공격 표면, 의존성, 리뷰 범위를 한꺼번에 줄였습니다. Claude는 친절해서 버튼을 추가하고 싶어 합니다. SPEC.md와 CLAUDE.md에 적어 두면 그 친절이 범위를 넘지 않습니다.

배포: 터널과 systemd

🔒 보는 방법: SSH 터널

콘솔은 운영 서버의 127.0.0.1에만 열립니다. 당번은 자기 PC에서:

ssh -N -L 8090:127.0.0.1:8090 ops@acme-ops-01 # 브라우저에서 http://127.0.0.1:8090

로그인 기능을 만들지 않은 대신, SSH 접근 권한이 곧 콘솔 접근 권한입니다. 이미 관리하고 있는 통제를 재사용합니다.

⚙️ 띄우는 방법: systemd

전용 비특권 사용자, 읽기 전용 파일시스템, 권한 없음. systemd-analyze verify로 단위 파일 문법을 확인했습니다.

[Unit] Description=ACME 운영 콘솔 (읽기 전용, 127.0.0.1) After=network-online.target [Service] Type=simple User=opsconsole WorkingDirectory=/opt/ops-console Environment=OPS_PORT=8090 Environment=PYTHONDONTWRITEBYTECODE=1 Environment=KUBECONFIG=/etc/ops-console/kubeconfig ExecStart=/usr/bin/python3 -m console.server Restart=on-failure NoNewPrivileges=yes ProtectSystem=strict ProtectHome=yes PrivateTmp=yes ReadOnlyPaths=/opt/ops-console CapabilityBoundingSet= RestrictAddressFamilies=AF_INET AF_UNIX [Install] WantedBy=multi-user.target
KUBECONFIG는 읽기 전용 계정

12편 원칙 그대로. ProtectHome=yes라 홈의 kubeconfig는 못 읽으니 /etc/ops-console/kubeconfig에 읽기 전용 서비스 계정으로.
