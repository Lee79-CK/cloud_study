Cloud 모니터링·로깅 실전 강의

Prometheus, Grafana, Loki, Alloy, OpenTelemetry, Tempo, Pyroscope, Mimir, OpenSearch로 여러 고객사를 관제하는 하이브리드 관측 플랫폼을 처음부터 만들고, 운영하고, AI가 읽을 수 있게 하고, 장애 훈련으로 마무리합니다. 각 편은 개념, 단계별 실습(복사 가능한 명령과 설정), 트러블슈팅, 용어 사전, 퀴즈로 이루어진 독립 HTML 파일입니다.

대상: 1~2년차 클라우드 엔지니어총 18편실습 환경: kind 2개 + Multipass VM 3대 + SeaweedFS
