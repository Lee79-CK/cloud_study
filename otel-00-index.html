05 · 이용 안내

파일 구성과 활용

파일은 같은 폴더에 두세요

목차의 링크는 같은 폴더의 파일을 가리킵니다. 13개 파일을 한 폴더에 넣으면 목차에서 바로 이동됩니다.

강의로 운영한다면

  • 1회차 — 1·2편 전원 공통. 경계선과 공용어를 먼저 맞춥니다
  • 2~3회차 — 트랙 분리. 개발자는 3~6편, 엔지니어는 7~10편
  • 4회차 — 11편 전원. RACI 편집기를 두 팀이 함께 채웁니다
  • 5회차 — 12편 전원. 장애 조사를 개발자·엔지니어 혼합 조로 진행

각 편은 다크 테마가 기본이며 우상단에서 라이트로 전환됩니다. 모든 편 하단에 용어집과 이해도 점검이 있습니다.

업무 산출물로 바로 쓰는 편

  • 3편 Java 에이전트 환경 변수 블록
  • 7편 Collector 파이프라인 YAML
  • 8편 Instrumentation CR · 적용 매니페스트
  • 11편 RACI 매트릭스 · 경계 계약서 (.md 다운로드)
  • 12편 실습 환경 매니페스트 (.yaml 다운로드)

기준 시점

모든 편은 2026년 9월 기준으로 작성되었습니다. 신호 성숙도(트레이스·메트릭·로그 Stable, 프로파일 Alpha), 시맨틱 컨벤션 안정화 현황, 에이전트·Collector 버전은 빠르게 바뀌는 영역이므로 실제 적용 전에는 공식 문서에서 최신 상태를 확인하세요.
